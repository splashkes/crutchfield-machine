- `ACTIONS.md` says "181 entries total" — likely stale after `rec.mp4.toggle`, `rec.mp4.codec`, and new META control actions landed. Regenerate with `./feedback --list-actions \| wc -l`.
- No `docs/features/MP4_RECORDER.md` and no `docs/features/EXR_RECORDER.md`. Both are first-class features used live; both need their own pages.
- No `docs/features/CAMERA.md`. The macOS Continuity Camera path is documented only by an inline comment.
- The user's installed `bindings.ini` has only a partial `[osc]` block (meta-controls + math toggle + MP4 toggle). No `link.*`, no `snapshot.*`, no `rec.toggle` OSC bindings. Either ship an updated bundled example or note in each feature doc that OSC entry points require user-side binding additions.
- SYPHON.md has a small contradiction about publish order vs overlay — fix the early paragraph or strike the "swap publish order" hint.
